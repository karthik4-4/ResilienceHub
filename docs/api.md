# REST API Reference & Integration Guide
## Supply Chain Disruption Response Coordinator (SCDRC)

The SCDRC application provides a production-ready asynchronous REST API built on **FastAPI** with automatic OpenAPI documentation.

Interactive Swagger documentation is available at:
```
http://localhost:8000/docs
```

---

## 1. Endpoints Overview

| Method | Endpoint | Description |
|---|---|---|
| `POST` | `/cases` | Ingest disruption report and coordinate multi-agent mitigation |
| `GET` | `/cases/{case_id}` | Retrieve case execution summary and final decision |
| `GET` | `/cases/{case_id}/blackboard` | Export complete immutable Blackboard snapshot |
| `GET` | `/cases/{case_id}/notifications` | Retrieve all generated stakeholder notification dispatches |
| `GET` | `/cases/{case_id}/trace` | Retrieve execution spans, agent latencies, and token metrics |
| `GET` | `/health` | System health check and component diagnostic status |

---

## 2. API Specifications

### 2.1 Submit Disruption Report
**Endpoint:** `POST /cases`

Initiates case creation, activates the Orchestrator, executes all 5 phases of agent coordination via the Blackboard, and returns the grounded decision.

#### Request Body
```json
{
  "report_text": "Primary supplier Apex Micro Systems (SUP-001) reports a 10-day delay in wafer production affecting shipment SHP-8801 of 1200 units of SKU-1042 destined for Chennai Electronics Manufacturing Plant (SITE-CHN-01). Severity: 4.",
  "case_id": "CASE-2026-001"
}
```

#### Response (`200 OK`)
```json
{
  "case_id": "CASE-2026-001",
  "status": "DECIDED",
  "decision": {
    "action": "REORDER",
    "chosen_option": "SUP-004",
    "total_cost_inr": 1943016.0,
    "confidence": 0.9,
    "rationale": "REORDER option SUP-004 chosen based on cost and viability analysis. Justified by Blackboard entries: E-0004, E-0005, E-0006, E-0007.",
    "cited_entries": ["E-0004", "E-0005", "E-0006", "E-0007"],
    "rejected": [
      {
        "option": "REORDER-SUP-012",
        "reason": "Viable but higher total landed cost (INR 2,062,435.20) vs chosen option (INR 1,943,016.00)"
      },
      {
        "option": "HOLD",
        "reason": "Stock cover (4.0 days) is insufficient for disruption duration (10 days)"
      }
    ]
  },
  "notify_count": 4,
  "blackboard_entries_count": 9,
  "duration_seconds": 0.05
}
```
